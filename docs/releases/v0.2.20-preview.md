# Yosh 0.2.20 developer preview

This Apple Silicon macOS preview adds a versioned terminal installer for the standalone runtime and the host plugin marketplace. The optional macOS App has a separate release track.

- The installer checks the archive's SHA-256 before extracting the package and opening the host menu.
- The menu detects installed Codex, Claude Code and Grok CLI and registers only the hosts you select. Dot opens a separate setup path for a private ChatGPT plugin and OpenAI tunnel.
- The Dot connector can install a pinned OpenAI tunnel client and verifies its checksum and macOS code signatures. Dot's pairing gives read-only access to the existing Mainnet statement.

On a fresh Mac, use the standalone settings for isolated Devnet. Mainnet requires an existing compatible Yosh Mainnet wallet, ledger and spending configuration. Follow the owner handoff when upgrading an active standalone runtime. [Local installation and upgrade](../guides/local-install.md) · [Host plugins and Dot](../guides/host-plugins.md)

Release assets include the installer script, the Yosh ZIP and a SHA-256 file for the ZIP.
