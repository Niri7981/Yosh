# Yosh v0.1.1 stable

Yosh Pay v1 is complete. Its final release candidate is **v0.1.1-rc.5**;
the stable App release is **Yosh v0.1.1, build 7**, promoted from the validated
final rc.5 implementation. The architecture generation does not change the
App semantic version to 1.0.0.

untouched. All rc profiles, historical Keychain entries and ledgers must remain.
Only the rc.5 `.app` bundle may be retired after the installed stable App and its
actual MCP path have passed continuity checks.

## Current build and installation entry

Use the canonical repository, locked npm dependencies, checksum-pinned Node
24.21.0 archive, the restored pinned Pay source plus its two archived overlay
files, the existing pinned pay-kit checkout, and restored offline Cargo vendor
inputs. The consolidation archive's `README.md` documents recovery. No deleted
rc worktree is a build input. Generated inputs stay under `build.noindex`.

```sh
npm ci --ignore-scripts --no-audit --no-fund
python3 -B scripts/build-stable-release.py check --pay build.noindex/stable-inputs/pay
python3 -B scripts/build-stable-release.py build \
  --pay build.noindex/stable-inputs/pay \
  --node-archive build.noindex/stable-inputs/node-v24.21.0-darwin-arm64.tar.xz \
  --cargo-home build.noindex/stable-inputs/cargo-home \
  --pay-kit /absolute/verified/pay-kit-checkout
```

The builder stages `build.noindex/release/v0.1.1-stable-build7/Yosh.app`; it
does not install, launch, access live Keychain or issue payments. It runs Node,
Rust, native and packaging regressions in a private macOS sandbox. Its temporary
sibling Pay alias exists only for historical test conventions and is removed.
The App ships its own runtime and Pay binaries. Its signed resources contain
`stable-source-manifest.json`; outer `stable-artifact.json` binds every bundle
file, symlink, mode and source manifest. Build steps and logs stay local.

After staging acceptance, quit the current App normally, wait for backend
shutdown, then install the already verified artifact:

```sh
scripts/install-macos-app.sh --stable-app \
  /Users/irin/Desktop/yosh/build.noindex/release/v0.1.1-stable-build7/Yosh.app
```

The installer rejects an existing `Yosh.app`, a running App or occupied profile
ports. It never creates configuration or product data. Startup verification and
Codex MCP path replacement happen separately; both keep the same persisted
profile and caller. Stable and rc.5 backends must never run together.

Local signatures are ad hoc, as for the accepted candidate. This promotion does
not assert Developer ID signing, notarization, public DMG publication, a Git tag
or a GitHub Release. The old Beta workflow is historical and does not build this
Pay v1 release. No commit or push is part of local stable acceptance.
